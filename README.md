# Gort Darts League - Organized prototype

This static prototype is split into clear folders for each league, shared data, styles, scripts, and future images.

## Structure

```text
gort-darts-league/
├── index.html
├── README.md
├── a-league/
│   ├── standings.html
│   ├── standings.js
│   ├── fixtures.html
│   ├── fixtures.js
│   ├── results.html
│   └── results.js
├── b-league/
│   ├── fixtures.html
│   ├── fixtures.js
│   ├── results.html
│   └── results.js
├── stats/
│   ├── index.html
│   └── stats.js
├── data/
│   └── league-data.js
└── assets/
    ├── css/
    │   └── style.css
    ├── js/
    │   └── home.js
    └── images/
```

## Run locally

Open `index.html` in a browser. For the most reliable local testing, serve the project folder with a simple local web server.

## Editing league content

All placeholder league content is stored in `data/league-data.js`.
